## 色まわりの機能：ソフトウェア側で色空間を切り替える

ProDesignerシリーズの特徴は、パネル単体の色域よりも、色管理をPC側から操作できる点にある。

- **Acer Creator Hub**：sRGB・DCI-P3・Adobe RGBなどの色空間の切り替え、色温度・輝度・RGBゲインの調整、カラープロファイルの保存に対応
- **Acer Display Widget**：ブルーライト・輝度・コントラスト・6軸カラー・彩度の設定、画面分割レイアウトの割り当てに対応

いずれもPCへのアプリケーションのインストールが必要で、Acerのサポートページから入手する形である。モバイルモニターのOSDボタンで色設定を追い込む作業は手間が大きいため、設定をPC側に寄せて保存できることは、出先と自宅で同じ見え方を再現したい用途と相性がよいと整理できる。

一方、マルチモニター環境で一部機能を使う場合は「モニターが同じサイズ・同じ解像度であること」が条件とされる。PE160Wと別サイズのモニターを混在させる構成では、分割レイアウト系の機能に制約が出ると想定される。

## 焼き付き対策：3つのOLED保護機能

有機ELをモバイルモニターとして使う際に気になるのは、タスクバーやツールパレットなど静止表示が長時間続くことによる焼き付きである。PE160Wには公式に以下の3機能が搭載されている。

| 機能 | 公式の説明（要約） |
|---|---|
| イメージリテンションリフレッシュ | 一定時間ごとに画面のピクセルをリフレッシュする |
| ピクセルセンタリング | 画面全体の負荷を均等に分散する |
| 静止画保護 | 同じ表示が続いた際に自動で輝度を調整する |

いずれも「リスクの軽減」であって、焼き付きが起きないことを保証するものではない。画像編集ソフトのように同じUIを何時間も表示し続ける用途では、ソフト側のダークテーマやパレットの自動非表示と組み合わせるのが現実的である。

## PE140W（14型）との違い

同じProDesignerの14型PE140Wsmiuuxと並べると、差分は次のとおりである。PE140Wの数値はAcer公式オンラインストアの仕様表による。

| 項目 | PE160Wsmiuux | PE140Wsmiuux |
|---|---|---|
| 画面サイズ | 16型 | 14型 |
| 解像度 | 1920×1200（WUXGA） | 1920×1200（WUXGA） |
| 画素密度（計算値） | 約141ppi | 約162ppi（画素ピッチ0.157mm） |
| 色域・認証 | DCI-P3 100%・Calman認証 | DCI-P3 100%・Calman認証 |
| リフレッシュレート／応答速度 | 60Hz／1ms | 60Hz／1ms |
| 端子 | HDMI 1.4×1、USB-C×2 | HDMI 1.4×1、USB-C×2 |
| 厚さ | 約13mm | 約13mm |
| 質量 | 約800g | 約600g |
| 価格 | 38,999円（直販） | 36,999円（公式ストア通常価格） |

解像度が同じWUXGAのまま画面が大きくなるため、PE160Wは表示できる情報量が増えるわけではなく、**同じ情報を大きく表示する**方向の変化である。文字やUIの見やすさを優先するなら16型、精細さと携帯性を優先するなら14型、という分かれ方になる。

重量差の約200gは、13〜14型ノートPC（おおむね1.0〜1.3kg）と一緒に持ち歩く前提では、合計重量を1〜2割押し上げる差として効いてくる。価格差は通常価格ベースで約2,000円と小さく、判断軸は価格よりも「画面の大きさ」と「持ち歩く頻度」に置くのが妥当と読み取れる。

## 16型OLEDの競合：ZenScreen OLED MQ16FCとの比較

16型・WUXGA・有機ELという同じ枠には、ASUSの [ZenScreen OLED MQ16FC](/gadget/zenscreen-mq16fc/) がある。

| 項目 | Acer PE160Wsmiuux | ASUS ZenScreen OLED MQ16FC |
|---|---|---|
| パネル | 16型 OLED、WUXGA、16:10 | 16型 OLED、WUXGA、16:10 |
| 色域 | DCI-P3 100%、Calman認証 | DCI-P3カバー率95%、ΔE 2未満 |
| 映像入力 | HDMI 1.4×1、USB-C×2 | miniHDMI×1、USB-C×2 |
| 給電 | PD対応（USB-C） | 最大65Wパススルー（双方向給電） |
| 質量 | 約800g | 約680g |

色域と色管理ソフトを重視するならPE160W、軽さと65Wパススルー給電によるケーブル整理を重視するならMQ16FC、という棲み分けになる。PE160Wのパススルー給電の上限値は、発表資料の範囲では明記されていない。ノートPCへの給電をモニター経由で完結させたい場合は、購入前に公式仕様表で確認しておきたい項目である。

モバイルモニター全体の選び方は [モバイルモニターの選び方](/gadget/mobile-monitor-guide/) で、FHD・WQXGA・OLED・タッチ対応の4タイプに分けて整理している。

## エンジニア視点で見るとどう使えるか

モバイルモニターを「出張・リモート時のサブ画面」として使う場合、ボトルネックになりやすいのは画面の色よりも**接続と給電**である。

- **USB-C 1本で完結する条件**：ノートPC側のUSB-CがDisplayPort Alt Modeに対応し、かつ給電を出せること。MacBook Air・MacBook ProのUSB-C／Thunderboltポートは映像出力に対応するが、モニターを駆動できる給電量はPC側の仕様次第で、Windows機も含めて機種ごとの確認が要る
- **HDMI接続時は別電源が必須**：HDMIでつなぐ場合はUSB-Cから電源を入れる必要があるため、ACアダプターやモバイルバッテリーをもう1つ持つ構成になる
- **USB 3.2 Gen 1（5Gbps）**：データ転送は5Gbpsまで。モニターを経由して高速ストレージをつなぐハブ的な使い方には向かない

16:10のWUXGAは、ターミナルとブラウザ、あるいはコードエディタとドキュメントを縦長に並べる用途と相性がよい。DCI-P3 100%の色域はコーディング用途では過剰だが、写真・動画の確認や資料のデザイン作業を兼ねるなら、1台で役割をまとめられる。

## 気になる点

- **Amazonの商品ページが未確認**：販路にAmazonが含まれているが、本記事の執筆時点では型番一致の商品ページを確認できていない
- **解像度はWUXGAのまま**：16型でも1920×1200のため、14型より精細さは下がる。高精細を求めるならWQXGA（2560×1600）クラスのモバイルモニターが候補になる
- **60Hz固定**：ゲーム用途やスクロールの滑らかさを重視する場合は、120Hz以上のモデルと比較する必要がある
- **HDR10とオーバードライブは同時使用不可**：公式の注記どおり、HDR表示と応答速度優先の設定はどちらかを選ぶ形になる
- **保証条件は要確認**：14型PE140Wの公式ストア表記は「3年（パネル・バックライトユニットは1年）」。PE160Wの保証条件は発表資料には記載がなく、有機ELの焼き付きが保証対象かどうかも含めて購入前の確認が必要

## まとめ

PE160Wsmiuuxは、14型PE140Wと同じ色域・認証・端子構成を保ったまま、画面を16型に広げたモデルである。解像度は据え置きのため、変化は「表示が大きくなる」ことと「約200g重くなる」ことに集約される。

価格差は約2,000円と小さく、選び分けの軸は明確である。持ち歩く日が多く精細さを取るなら14型、据え置きに近い使い方で文字の見やすさを取るなら16型。さらに給電の取り回しや軽さを優先するなら、同じ16型OLEDのMQ16FCも比較対象に入る。
