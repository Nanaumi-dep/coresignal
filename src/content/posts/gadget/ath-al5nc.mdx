ノイズキャンセリングヘッドホンは、ハウジングを閉じて物理的に音を遮り、そのうえで残った低音域を逆位相の音波で打ち消す、という二段構えで静けさを作ってきた。オーディオテクニカが2026年9月18日に発売する ATH-AL5NC は、この一段目を意図的に外している。型式はオープンエアーダイナミック型、つまり開放型である。直販価格は39,600円。

開放型は背面が抜けているため遮音がほぼ効かない。そこにアクティブノイズキャンセリングだけを載せると何が残るのか。公式が示す抑制範囲と、密閉型モデルとの仕様差から整理する。なお本記事の仕様はメーカー公式サイトの公開情報に基づく。

## 開放型でノイズキャンセリングが成立する範囲

公式の説明は「エアコン音や走行ノイズなど低〜中音域の不要な雑音だけをアクティブノイズキャンセリングが的確に抑制します」という書き方になっている。全帯域を静める、とは書いていない。ここが仕様の要点である。

アクティブノイズキャンセリングは、マイクで拾ったノイズの逆位相を生成して打ち消す方式のため、波長が長く位相を合わせやすい低い音ほど効きやすく、波長の短い高域ほど処理が追いつかない。密閉型はこの苦手な高域をハウジングとイヤパッドの物理的な遮音で埋めていた。開放型にはその物理層がない。

結果として ATH-AL5NC で静かになるのは、空調の唸り、電車や車の走行音、PCのファン音といった連続した低〜中音域に寄る。逆に、周囲の話し声の子音、食器の音、キーボードの打鍵音のような高域成分は、開放型の構造どおりそのまま耳に届くと整理できる。公式が「外の世界とつながりながら」「話しかけられれば気づける」と表現しているのは、この残り方を欠点ではなく仕様として位置づけたものと読み取れる。

抑制の強度は Home と Airplane の2段で切り替えられる。騒音の少ない室内では弱め、機内など騒音下では強めという使い分けになる。

## Bluetoothを切っても100時間動くスタンドアローンモード

仕様面でもっとも特徴的なのは、Bluetooth接続をせずノイズキャンセリング機能だけを動かす「スタンドアローンモード」である。音楽を再生せず、周囲のノイズだけを抑える耳栓的な使い方を想定した機能になる。

- Home モードで最大約100時間、Airplane モードで約80時間
- Bluetooth接続を行わないため電池消費が小さい
- デバイス未接続時のオートパワーオフが作動しない

3つ目が運用上は効く。通常のワイヤレスヘッドホンは接続先がない状態が続くと自動で電源を落とすため、「音は流さずノイズだけ消したい」という使い方をすると勝手に切れる。この製品はその挙動を止めている。

有線接続時にもノイズキャンセリングが使える点も同じ方向の設計である。付属コードで機内エンタメシステムやミキサーにつないでも、静けさの側は生きたまま残る。

## 密閉型ANCとの棲み分け

同社の密閉型ワイヤレスANCヘッドホン ATH-S300BT（2024年6月発売）と並べると、設計思想の違いがそのまま仕様差に出る。

| 項目 | ATH-AL5NC | ATH-S300BT |
|---|---|---|
| 型式 | オープンエアーダイナミック型 | 密閉ダイナミック型 |
| ドライバー | φ53mm | φ40mm |
| 再生周波数帯域 | 20〜40,000Hz | 20〜20,000Hz |
| インピーダンス | 52Ω | 44.5Ω |
| Bluetooth | Ver.5.3 | Ver.5.1 |
| 対応コーデック | LDAC / AAC / SBC | AAC / SBC |
| 連続再生（ANC ON） | 最大約50時間 | 最大約60時間 |
| 連続再生（ANC OFF） | 最大約75時間 | 最大約90時間 |
| 有線接続時のANC | 使用可 | 使用不可（機能OFF） |
| 質量 | 約240g | 約258g |

注目すべきは有線接続時の行が逆転している点である。密閉型の S300BT は有線にするとアンビエンスコントロール機能そのものがOFFになる。対して AL5NC は有線でもノイズキャンセリングが残る。バッテリー駆動時間は S300BT のほうが長いが、これは遮音を物理構造に任せられる分だけ電気的な処理の負荷が軽い、という関係とも整合する。

ハウジング構造ごとの選び分けは [ヘッドホンの選び方](/gadget/headphone-guide/) で4タイプに分けて整理している。

## エンジニア視点で見るとどう使えるか

在宅作業のデスクで一日中装着する前提で見ると、この製品が解こうとしている問題は「静けさ」ではなく「装着コスト」のほうである。

密閉型ANCを8時間連続で着け続けると、側圧による頭部の圧迫と、イヤパッド内部にこもる熱が効いてくる。AL5NC は約240gという質量に加えて低側圧設計と開放型構造を組み合わせ、その2点を削りに来ている。抑制できるノイズの範囲は狭くなるが、空調とPCファンという在宅作業で常時鳴っている音は、まさに公式が挙げる低〜中音域側に入る。

もう一点は、同居者や来客に対して反応できる状態を保てることである。密閉型ANCは外音取り込みモードをオンにしない限り呼びかけに気づけないが、開放型は構造として気づける。専用アプリ「Connect」にはマルチポイント2台接続、低遅延モード、キーアサイン、16/32/64段階の音量ステップ切り替えが用意されており、PCとスマートフォンを行き来する運用にも対応する。Web会議を主目的にするならマイクブーム付きの [ATH-M20xSTS](/gadget/ath-m20xsts/) のようなヘッドセット型が別の解になる。

## 気になる点

**遮音の絶対量は密閉型に届かない。** 前述のとおり高域は構造上そのまま入る。カフェの話し声や駅のアナウンスを消したい用途では、素直に密閉型を選んだほうが目的に合う。公式も音漏れ抑制モードについて「完全に音漏れを防ぐものではありません」と明記している。

**LDACと低遅延モードは排他である。** 公式仕様に「LDACコーデック選択時は、低遅延モードがOFFになります」とある。高音質と低遅延のどちらを取るかは、アプリ側でその都度切り替える運用になる。

**LE AudioやLC3への言及がない。** Bluetooth は Ver.5.3準拠で、対応プロファイルは A2DP / AVRCP / HFP / HSP。同じ9月18日発売のソニー [WH-CH730N](/gadget/wh-ch730n/) が Bluetooth 6.0 と LC3 を掲げているのと比べると、通信規格の世代では一歩手前に位置する。

**価格帯が密閉型の主力と重なる。** 39,600円は各社の密閉型ANCミドルクラスと同じ価格帯である。遮音量で比較すると不利になるため、「圧迫感と蒸れを減らしたい」という動機がどれだけ強いかで評価が分かれる製品になる。

## まとめ

ATH-AL5NC は、ノイズキャンセリングヘッドホンの遮音を担ってきた密閉構造をあえて外し、アクティブノイズキャンセリングだけで低〜中音域を抑える構成を取った。消せる音の範囲は狭くなる代わりに、約240gと低側圧、通気する開放型ハウジングという形で長時間装着側のコストを下げている。

Bluetooth未接続で最大約100時間動き、オートパワーオフも作動しないスタンドアローンモードと、有線接続時もノイズキャンセリングが残る仕様は、同社の密閉型 ATH-S300BT にはない。用途が「外界を遮断する」ではなく「不要な定常音だけ下げて一日着けたままにする」側にあるなら、選択肢として成立する1台と整理できる。装着方式ごとの違いは [ワイヤレスイヤホンの選び方](/gadget/earphone-guide/) でも扱っている。
