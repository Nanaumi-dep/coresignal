据え置きで使う大画面タブレットは、置き場所と充電ケーブルの取り回しが最後まで解決しない。テレビ台の横やキッチンのカウンターに立てておきたいが、ケーブルを挿しっぱなしにすると抜き差しのたびに端子を痛め、抜いておくと肝心なときに電池が切れている。

アイリスオーヤマが2026年9月15日に発表した「LUCA ワイヤレス充電対応タブレット 15.6inch」（TM15F1Q74-V1H）は、この2点をまとめて背面のマグネットで処理する設計になっている。発売は2026年9月24日で、同社公式通販のアイリスプラザでは9月15日から予約販売が始まっている。同時発売の「LUCA ワイヤレス充電タブレットスタンド」（IST-B151Q-B）に載せるだけで、固定と充電が同時に成立するという構成である。

15.6型という画面サイズと、Unisoc T620・RAM 4GB＋仮想4GBという構成の組み合わせが何を意味するのか、公式仕様から整理する。

## 背面マグネットとスタンド15Wの関係

本体背面に独自のマグネット機構を搭載し、専用アクセサリを吸着させる構造になっている。スタンド（IST-B151Q-B）はあらかじめ電源に接続しておく前提で、タブレットを載せた時点で固定と給電が同時に始まる。チルト角度は15°と35°の2段階で、スタンド自体の質量は約553g、充電器とType-C – Type-Cケーブルが同梱される。

注目すべきは出力の数字である。スタンド経由のワイヤレス充電は**最大15W**、対して本体の有線急速充電は**9V2A＝18W**。つまり置くだけの運用は、有線より遅い側の選択肢になる。8000mAh（公称3.7V換算で約29.6Wh）を15Wで賄う計算になるため、ゼロから満充電を狙う用途ではなく、「使っていない時間はスタンドに戻して常に80%前後を維持する」という運用に噛み合う設計と整理できる。据え置き前提の機器で充電速度を競う意味は薄く、ケーブルを触らない体験のほうを取った構成と読み取れる。

なお、リリースでは充電規格の名称（Qi / Qi2 など）は明示されておらず、対象機種も TM15F1Q74-V1H に限定して記載されている。手持ちのQi対応機器を載せて使う汎用充電台として期待するのは避けたほうがよい。ワイヤレス充電の規格ごとの出力差については[ワイヤレス充電器の選び方](/gadget/qi2-charger-guide/)で整理している。

もう一方のアクセサリ「LUCA タブレットリング」（SX-28YA-B）は、折りたたみ時で約110×109.3×9.3mm、材質は磁石・アルミニウム合金・樹脂。リングに手を通して片手で保持するほか、スタンド代わりに立てる、壁や棚のフックに掛けるといった使い方が想定されている。約1083gの本体を片手で支える前提の製品であり、掛ける先のフックの耐荷重は確認しておきたいところである。

## 先代15.6型との仕様差

同社の15.6型は TM153M6V1-B が直近の世代にあたる（公式サイト上は生産終了扱い）。新型との差は、ワイヤレス充電対応という一点だけではない。

| 項目 | TM15F1Q74-V1H（新） | TM153M6V1-B（先代） |
|---|---|---|
| OS | Android 16 | Android 13 |
| CPU | Unisoc T620 | MT8788（8コア） |
| RAM | 4GB＋仮想4GB | 6GB |
| ストレージ | 128GB | 128GB |
| バッテリー | 8000mAh | 9200mAh |
| ディスプレイ | 15.6型 1920×1080 | 15.6型ADS 1920×1080 |
| Wi-Fi | 802.11a/b/g/n/ac | 802.11a/b/g/n/ac |
| サイズ | 366×234×10.1mm | 366×224×10mm |
| 質量 | 約1083g | 約1.2kg |
| 背面マグネット | あり | なし |

OSは3世代進み、質量は約120g軽くなっている。一方で物理RAMは6GBから4GBへ、バッテリーは9200mAhから8000mAhへ減っている。

RAMの「4GB＋4GB」表記は、後半がストレージの一部をメモリとして一時的に代用する仮想メモリであり、この点はリリースの注釈にも明記されている。注釈では実際の動作速度が物理メモリと比べて低下する場合があると断られており、数字の合計をそのまま物理6GBと比べるのは適切ではない。アプリを複数立ち上げたまま切り替える使い方では、先代より不利になる可能性がある。

バッテリー減は、スタンドに常時載せる運用が前提なら影響は小さい。ただしリングを付けて家の中を持ち回る使い方を想定するなら、容量が15%近く減っている事実は効いてくる。

## 通信と端子まわりの制約

Wi-Fiは 802.11a/b/g/n/ac 表記で、Wi-Fi 5世代である。先代から据え置きで、Wi-Fi 6／6Eへの更新は入っていない。1080pの動画配信を1台で受ける用途では実用上の問題になりにくいが、家庭内の回線がWi-Fi 6以降のルーターで統一されている環境では、この端末だけが5GHz帯の旧世代で接続することになる。同一チャネルを共有する他機器のスループットに影響しうる点は、ネットワーク側の設計として意識しておきたい。

有線側も同様で、USB Type-C端子はUSB 2.0仕様。外部ストレージから大容量の動画ファイルを流し込む用途では転送速度が上限になる。ディスプレイ出力についてはリリースに記載がなく、外部モニターへの映像出力は想定されていないと読むのが妥当である。

Widevine L1準拠は明記されており、対応する動画配信サービスをHD画質で再生できる。15.6型を配信視聴に使う前提なら、この項目が欠けていないことは実用上大きい。[モバイルモニターの選び方](/gadget/mobile-monitor-guide/)で扱った外部ディスプレイ的な使い方とは別物で、あくまで単体で完結する視聴端末として設計されている。

## 気になる点

第一に、充電器が本体に同梱されない。スタンドと同時に揃えれば充電器は付いてくるが、タブレット単体の場合は9V2A対応の充電器を別途用意する必要がある。

第二に、ワイヤレス充電の規格が公表されていない。専用スタンドとの組み合わせ以外での互換性が読めないため、スタンドが故障・廃番になったときの代替手段が現時点では不明である。長期運用の観点では、有線充電が使える構成であることが保険になっている。

第三に、物理RAM 4GBという構成。15.6型という画面サイズは複数アプリの同時表示に向くが、その使い方をするほどメモリが効いてくる。仮想メモリはストレージ容量を消費する仕組みでもあり、128GBの実効容量にも影響する。

第四に、参考価格がオープン価格で、公式リリースには実売価格の記載がない。予約はアイリスプラザで始まっているため、購入判断には実際の販売価格の確認が必要になる。

## まとめ

TM15F1Q74-V1H は、スペックシートの数字を積み上げて評価する種類の製品ではない。先代からRAMとバッテリーが減っている以上、処理性能や電池持ちで選ぶ理由は薄い。

この製品の中心は、背面マグネットとスタンドによる「置けば充電、取れば持ち出し」という運用の単純化にある。リビングやキッチンに定位置を作り、ケーブルを一度も触らずに大画面を使い回す構成が成立するかどうかが判断の分かれ目になる。その運用に合わせるなら、15Wという控えめな充電出力もバッテリー容量の減少も、設計の辻褄として整理できる。

逆に、持ち歩いて使う、複数アプリを並べて作業する、Wi-Fi 6の環境を活かしたいといった要求があるなら、この端末の設計思想とは方向が合わない。
