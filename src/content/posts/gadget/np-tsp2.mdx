パナソニックが2026年8月5日に発表した卓上型食器洗い乾燥機「NP-TSP2」が、2026年9月中旬より発売される。分岐水栓の取り付け工事が不要なタンク式で、賃貸住宅でも導入できる系統の製品である。

タンク式食洗機は「工事がいらない代わりに小さい」という理解をされがちだが、NP-TSP2で公式が押し出しているのは容量そのものではなく、**同じ24点の容量のまま、フライパンなどの調理器具も一緒に入るようにした**という点にある。先代NP-TSP1との公式仕様を並べると、変わったところと変わっていないところがはっきり分かれる。ここでは差分と、設置時に効いてくる寸法を整理する。

## 先代NP-TSP1から変わった点

同じタンク式スリムの先代NP-TSP1と公式仕様を突き合わせると、差分は以下に集約される。

| 項目 | NP-TSP1 | NP-TSP2 |
|---|---|---|
| 容量 | 24点 | 24点 |
| 標準使用水量 | 約9L | 約9L |
| 消費電力量 | 約670Wh | 約670Wh |
| 運転時間（汚れレベル2） | 約93分/88分 | 約93分/88分 |
| スピーディコース | 非搭載 | 約26分 |
| 80℃すすぎ | 非搭載 | 搭載（洗浄・乾燥運転+約7〜15分） |
| 低温ソフトコース | 搭載 | 非搭載 |
| タンブラー＆ボトルホルダー | 非搭載（上かごで兼用） | 搭載 |
| ドア開時の奥行最大（上部） | 386mm | 433mm |
| 製品質量 | 約19kg | 約18kg |

洗浄性能を決める数値、つまり水量・消費電力量・標準的な運転時間はすべて据え置きである。変わったのは**庫内のかごの構造と、コースの選択肢**という整理ができる。

公式リリースによれば、上かごをコンパクトに畳むことで奥行の有効スペースを従来比約40mm拡大し、2人分の食器12点に加えてフライパンや鍋も入るようにしたとされる。対応する調理器具のサイズは全長45cm以下・直径26cm以下・高さ6.5cm以下と明記されている。フライパンが入るかどうかは、この3つの数字で事前に判断できる。

## タンク式と分岐水栓式で何が変わるか

同じパナソニックの卓上型には、奥行約29cmの分岐水栓式スリムタイプ「NP-TSK2」もある。タンク式との違いは、給水の手間と設置条件のトレードオフに集約される。

| | タンク式（NP-TSP2） | 分岐水栓式（NP-TSK2） |
|---|---|---|
| 給水 | 本体タンクに手で注ぐ | 水栓から自動給水 |
| 設置工事 | 不要 | 分岐水栓の取り付けが必要 |
| 賃貸での導入 | 工事なしで置ける | 水栓の型番確認と工事が前提 |
| 排水 | 排水ホース約1m（シンクへ） | 同様に排水ホース |

タンク式は「工事がいらない」ことが最大の利点だが、その代わり毎回タンクへ注水する操作が入る。1回あたり約9Lという水量は手洗い（公式試算では約51L）と比べれば少ないが、それでも注ぐ操作は発生する。ここを許容できるかが、タンク式を選べるかどうかの分岐点になる。

なお給水方式が違っても、庫内の洗浄方式そのものは変わらない。工事の可否だけで選び分けてよい部分と言える。

## 設置で効くのは本体寸法よりドア開時の奥行き

カタログに載る本体奥行は341mmで、これは先代と同じである。しかし設置を検討するときに効いてくるのは、ドアを開けたときの最大寸法のほうだ。

NP-TSP2はリフトアップオープンドアを採用しており、公式仕様のドア開閉時最大奥行は上部433mm・下部362mmと記載されている。先代NP-TSP1の同項目は上部386mm・下部362mmだった。つまり**本体の設置奥行は据え置きのまま、ドアを開けたときに上部で必要になる前方クリアランスが約47mm増えている**。

シンク横のカウンターに置く場合、背面を壁に寄せて341mmで収まったとしても、ドアを持ち上げた瞬間に433mm相当の空間を使う。吊り戸棚の下や、カウンター奥行が浅い環境では、ここが通らずに開けられないという事態が起こり得る。測るべきは「置ける奥行」ではなく「開けられる奥行」であり、高さも同様に600mm（ドア開時712mm）の2つを見る必要がある。

電源まわりも確認対象になる。最大消費電力は50Hzで1168W、60Hzで1188Wと、単体で1kWを超える。電源コードは約1.9m、アース線は約2mで、アース付きコンセントが届く位置かどうかが設置可否を決める。延長コードでの引き回しは推奨されない領域の消費電力である。

## 1回あたりのコストを数字にする

公式が試算に用いている単価は、電力料金が31円/kWh（家電公取協調べ・2022年7月改定）、水道料金137円/㎥・下水道使用料125円/㎥（日本電機工業会調べ）と明記されている。これをNP-TSP2の公式仕様に当てはめると、1回あたりのコストは以下のように計算できる。

| 項目 | 計算 | 1回あたり |
|---|---|---|
| 電気代 | 0.67kWh × 31円 | 約20.8円 |
| 水道・下水 | 0.009㎥ × 262円 | 約2.4円 |
| 合計（洗剤別） | ー | 約23円 |

1日1回・30日運転すると電気と水で月約700円、1日2回なら月約1,400円という水準になる。先代NP-TSP1の公式試算では、1日2回・毎日使用した場合に手洗いと比べて年間約11,300円の節約になるとされている。NP-TSP2は水量・消費電力量が先代と同一なので、同等の水準と読み取れる。

判断材料として重要なのは、この金額が**本体価格を何年で回収するかではなく、毎日の後片付けの時間を月1,400円程度で外注できるか**という問いに変換できる点である。スピーディコース約26分の追加は、この「時間を買う」性格をより前面に出した変更と整理できる。

## 気になる点

第一に、低温ソフトコースが落ちている。NP-TSP1には搭載されていた低温ソフトコース（合計約147〜142分）が、NP-TSP2の公式仕様では非搭載となっている。耐熱温度の低い樹脂製品やコーティング品を洗う想定で使っていた場合、この差は実用上の後退になる。スピーディと80℃すすぎが増えた代わりに、低温側の選択肢が減ったという構図である。

第二に、お手入れの手順が変わっている。NP-TSP1は専用の「お手入れコース」を持っていたが、NP-TSP2では標準使用量の2倍の食洗機専用洗剤を入れて食器なしで「汚れレベル3」を運転する方式になっている。月2〜3回の実施が推奨されるのは両機種共通だが、操作としては一段わかりにくくなった。

第三に、価格が公式発表の時点で明示されていない。発売時期も「2026年9月中旬」と幅のある表記であり、リリースにも社会情勢等の影響で発売が延期される可能性がある旨の注記が付いている。

第四に、記事作成時点でAmazon.co.jpにNP-TSP2の商品ページが確認できていない。先代NP-TSP1と分岐水栓式のNP-TSK2は掲載済みであるため、当面は先代が実売価格の目安になる。

## まとめ

NP-TSP2は、洗浄性能の数値を据え置いたまま、庫内の使い方とコースの選択肢を組み替えたモデルと整理できる。水量約9L・消費電力量約670Wh・運転時間約93分という基本部分は先代NP-TSP1と同一で、差が出るのは調理器具が入るようになった点、スピーディ約26分と80℃すすぎが加わった点、そして低温ソフトコースが落ちた点である。

導入を検討する場合、最初に測るべきは本体奥行341mmではなく、ドアを開けたときに必要な上部433mm・高さ712mmのほうだ。工事不要という利点は設置場所の制約を外してくれるが、開閉スペースの制約までは外してくれない。同じパナソニックの生活家電では、[冷蔵庫のERタイプ3機種](/gadget/nr-f52er4/)でもカタログ表記と実際の設置寸法の読み方が論点になっており、卓上型でも見る順番は同じである。
