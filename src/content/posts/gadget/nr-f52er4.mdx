パナソニックが冷凍冷蔵庫の新モデルとして「NR-F52ER4」「NR-E47ER4」「NR-E47ER4L」の3機種を発表した。発売は2026年10月23日で、価格はオープン。いずれも出し入れの多い野菜を中央に置く「野菜室が真ん中」タイプにあたる。

本稿は発売前段階の情報として、公式製品ページの仕様表に載っている数字だけを対象に整理する。店頭価格や実売の使い勝手には踏み込まない。

## 3機種の基本スペック

公式仕様に記載された主要数値は以下のとおり。NR-E47ER4とNR-E47ER4Lはドアの開き方向だけが異なる同一仕様で、前者が右開き、後者が左開きとなる。

| 項目 | NR-F52ER4 | NR-E47ER4 / NR-E47ER4L |
|---|---|---|
| 定格内容積 | 515L | 468L |
| 冷蔵室 | 262L（うちチルド21L） | 238L（うちチルド18L） |
| 野菜室 | 104L | 95L |
| 冷凍室 | 103L | 93L |
| 新鮮凍結ルーム／上段冷凍室 | 29L | 25L |
| 製氷室 | 17L | 17L |
| 年間消費電力量（50/60Hz） | 272kWh/年 | 257kWh/年 |
| 省エネ基準達成率（2021年度基準） | 105% | 105% |
| 外形寸法（幅×奥行×高さ） | 650×699×1850mm | 600×699×1850mm |
| 質量 | 94kg | 87kg |
| カラー | マットブラック／マットホワイト | マットブラック／マットホワイト |

幅が50mm違うだけで定格内容積は47L差がつく。高さと奥行きは3機種とも共通で、設置面のハードルは幅で決まる構造になっている。

## 「515L」と「現実に入る量」は別の数字である

冷蔵庫のカタログで最初に目に入る容量は**定格内容積**で、JIS C 9801-3:2015 の測定方式にもとづく庫内の容積を指す。これとは別に、公式仕様表には**食品収納スペースの目安**という数字が併記されている。棚やケース、冷気の通り道を除いた「食品を置ける現実的な体積」がこちらにあたる。

NR-F52ER4の各室を両方の数字で並べると差が見える。

| 室 | 定格内容積 | 食品収納スペースの目安 |
|---|---|---|
| 冷蔵室 | 262L | 206L |
| 野菜室 | 104L | 74L |
| 冷凍室 | 103L | 73L |
| 新鮮凍結ルーム | 29L | 13L |
| 製氷室 | 17L | 4L |
| 合計 | 515L | 370L |

515Lに対して目安は370Lで、比率にすると約72%になる。差が最も大きいのは製氷室と新鮮凍結ルームで、製氷皿やアルミプレートが占める分が引かれている。冷蔵室も262Lに対して206Lと、ガラストレイの厚みぶんだけ目減りする。

つまり「500L超えの大型」という表記だけで容量を見積もると、4分の1以上を見誤ることになる。機種間の容量比較は定格内容積どうしで行い、置きたい食材の量から選ぶときは食品収納スペースの目安を見るのが、仕様表の正しい読み分けになる。

## 先代との差は省エネに集中している

468Lモデルの先代にあたるNR-E47BR3と、新モデルのNR-E47ER4を公式仕様で突き合わせると、変化が一箇所に偏っていることがわかる。

| 項目 | NR-E47BR3（先代） | NR-E47ER4（新） |
|---|---|---|
| 定格内容積 | 468L | 468L |
| 外形寸法 | 600×699×1850mm | 600×699×1850mm |
| 年間消費電力量 | 270kWh/年 | 257kWh/年 |
| 省エネ基準達成率 | 100% | 105% |
| 質量 | 84kg | 87kg |

容量も寸法も据え置きで、年間消費電力量が13kWh/年、率にして約4.8%下がっている。省エネ基準達成率は100%から105%へ切り上がった。質量が3kg増えているのは、断熱材の増量が主因と読み取れる方向の変化になる。

年間消費電力量の差を電気代に置き換えると、1kWhあたり31円で換算した場合に年403円ほどの差になる。買い替えの決め手になる額ではないが、10年使う前提なら4,000円規模の差として積み上がる。エアコンの省エネ性能を年単位で見たときと同じ考え方で、[霧ヶ峰ZWの2027年度モデル](/gadget/kirigamine-zw-f1/)でも最小能力と年間消費電力量がセットで語られている。

なお515LのNR-F52ER4は272kWh/年で、468Lモデルより15kWh/年多い。容量あたりで割ると大型機のほうが効率が良い計算になるが、絶対値の電気代は増える。

## 設置条件は「幅」より「開いたときの奥行き」で決まる

据付必要奥行寸法は3機種とも699mmで、本体の奥行きと同じ値が公式仕様に記載されている。ただし据え付けの可否を左右するのは静止状態の寸法ではない。

同じERタイプの先代モデルの寸法図には、冷蔵室ドア開放時の最大奥行が1,261mm、冷凍室を最大まで引き出したときの奥行が1,200mmと明記されている。本体奥行き699mmに対して、ドアと引き出しの動作域はおよそ1.8倍に達する。キッチンの通路幅がこの動作域を飲み込めるかどうかが、実質的な設置条件になる。

公式が案内している余裕の取り方は次のとおり。

- 設置条件により寸法が若干変わるため、10mm程度の余裕を確保する
- 壁ぎわに設置して冷蔵室ドアが十分に開けられない場合は、壁から15mm以上のスペースを空ける
- 背面・上部の空きスペースは最小必要設置スペースであり、年間消費電力量の測定条件とは異なる

最後の一文は見落としやすい。カタログの272kWh/年や257kWh/年は、最小設置スペースで運用したときの値ではない。放熱が阻害される置き方をすれば、実消費は仕様値から離れていく。省エネ性能を数字どおりに引き出したいなら、ぎりぎりの寸法で押し込む設置は避けたほうがよい。

## 3機種のどれを選ぶか

判断材料は3つに絞れる。

**幅**：キッチンの間口が650mmを許容できるならNR-F52ER4、600mmまでならNR-E47ER4系になる。高さ1850mmと奥行699mmは共通なので、比較すべき軸は幅だけに単純化される。

**ドアの開き方向**：NR-E47ER4（右開き）とNR-E47ER4L（左開き）は仕様が同一で、価格帯も同列に並ぶ。壁や通路の位置関係だけで決まる選択になる。逆に言えば、開き方向を間違えると仕様面では取り返しがきかない。

**冷凍と野菜のどちらを優先するか**：515Lモデルは冷凍室103L・野菜室104Lでほぼ同容量、468Lモデルは冷凍室93L・野菜室95Lで比率はほぼ同じ。どちらも冷凍室に「霜つき抑制冷凍」が入り、14日間にわたって霜つきを抑える制御が働く。冷凍保存の比重が高い使い方をしても、容量比では差別化されない構成になっている。

## 気になる点

**価格がオープンで、比較の土台が公式情報だけでは作れない**。年間消費電力量や容量は公式仕様で確定するが、費用対効果を計算するには実売価格が必要になる。発売前の段階では、省エネ差の年403円を回収できるかどうかは判断できない。

**食品収納スペースの目安が新モデル全機種ぶん揃っていない**。NR-F52ER4の仕様表には併記されているが、NR-E47ER4については公式仕様の該当欄が確認できていない。468Lモデルで実容量を見積もる場合は、先代NR-E47BR3の目安値（合計341L相当）を参考値として扱うことになる。

**AIカメラやアプリ連携は本シリーズの訴求軸ではない**。上位のWXタイプなどで展開されている機能群は、ERタイプの公式仕様には記載がない。庫内管理をアプリ側で行いたい用途では、シリーズ選択の段階から見直す必要がある。

## まとめ

新ERタイプ3機種の変更点は、容量や寸法ではなく省エネ性能に集中している。468Lモデルは先代から年間消費電力量が13kWh/年下がり、省エネ基準達成率が100%から105%へ上がった。一方で定格内容積・外形寸法・据付必要奥行はいずれも据え置きで、買い替え時の設置検討は先代の寸法図をそのまま流用できる範囲に収まる。

読み解きで押さえておくべきは、定格内容積と食品収納スペースの目安が別の数字だという点と、年間消費電力量が最小設置スペースでの測定値ではないという点の2つ。どちらも仕様表の脚注に書かれている情報で、カタログの大きな数字だけを追うと見落とす。パナソニック製品の年間消費電力量の扱いは[ビエラ S60C](/gadget/viera-s60c/)でも同じ構造で、表示値の前提条件まで確認してから比較するのが妥当な進め方になる。
